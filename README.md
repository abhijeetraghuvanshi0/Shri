# S.H.R.I. — Unified Autonomous AI Agent Operating System

**Developer:** Abhijeet Raghuvanshi

**S.H.R.I.** (`/shri`) is a single, self-contained `SKILL.md` file that bundles **27 specialized workflows + MCP integrations** into one unified AI agent operating system — built so a single `/shri` command can take an app from idea to tested, reviewed, production-ready delivery, as well as handle YouTube growth/production, UI design, and reverse engineering.

---

## What's Inside This Single File?

### 1. End-to-End App Builder Pipeline (`0 -> Production`)
Discovery & Spec -> UI Design (`StitchMCP` / HTML Mockup) -> Git Worktree Isolation -> Bite-Sized Plan -> Red-Green TDD Build -> Code Review -> Verification Gate -> Merge / PR.

### 2. Software Engineering Suite (15 Workflows)
- **Brainstorming & Spec Design** (structured discovery + design gate before coding)
- **UI Design (`StitchMCP` + Visual Companion)**
- **Git Worktrees & Isolation** (safe branching + `.gitignore` verification + auto-setup)
- **Writing Plans** (vertical slices, `Consumes`/`Produces` interfaces, 5-point self-review)
- **Executing Plans & Subagent-Driven Dev** (ledger tracking, fresh reviewers, 5-round breaker)
- **Dispatching Parallel Agents** (concurrent execution across independent domains)
- **Test-Driven Development (TDD)** (strict Red-Green-Refactor enforcement)
- **Systematic Debugging** (4-phase root-cause investigation + 3-fix architectural stop rule)
- **Requesting & Receiving Code Review** (read-only review templates, YAGNI checks)
- **Verification Before Completion** (fresh command evidence gate)
- **Finishing a Development Branch** (local merge, PR creation, safe worktree cleanup)
- **Skill Authoring & Session Diagnostics**

### 3. YouTube Creator & Growth Suite (11 Workflows + 21 Hook Formulas)
`yt-audit` • `yt-viral` • `yt-plan` • `yt-script` • `yt-package` • `yt-edit` • `yt-shorts` • `yt-chapters` • `yt-seo` • `yt-retention` • `yt-comment`

### 4. Reverse Engineering Suite (`rea` MCP)
Target routing for native binaries (PE/ELF/Mach-O), Electron/ASAR/JS, Android APKs, .NET, Go/Rust metadata, firmware, browser captures, HAR/SAZ, PCAP, WASM, EVM, SQLite, and ELF core dumps.

## Installation (Works on Any Device)

You only need the single **`SKILL.md`** file (or download [`S.H.R.I.-Skill-Bundle.zip`](./S.H.R.I.-Skill-Bundle.zip)).

### Google Antigravity
- **Global (all projects):**
  - Windows: `C:\Users\<YOUR_USER>\.gemini\config\skills\shri\SKILL.md`
  - macOS / Linux: `~/.gemini/config/skills/shri/SKILL.md`
- **Project-scoped:** `<your-project>/.agents/skills/shri/SKILL.md`

### Claude Code (Anthropic)
- **Global (all projects):**
  - Windows: `C:\Users\<YOUR_USER>\.claude\skills\shri\SKILL.md`
  - macOS / Linux: `~/.claude/skills/shri/SKILL.md`
- **Project-scoped:** `<your-project>/.claude/skills/shri/SKILL.md`

### Claude.ai (Web / Desktop Projects)
Upload [`SKILL.md`](./SKILL.md) directly into **Project Knowledge** or paste its contents into **Project Instructions**.

---

## Usage

Once installed, simply invoke:

```text
/shri Build a full-stack task manager app with auth and tests
```

S.H.R.I. automatically selects and runs the required internal workflows without asking you to pick tools manually.
